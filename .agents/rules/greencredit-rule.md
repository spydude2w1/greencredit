# Green Credit AI — System Instruction Rules

## Core Objective

This project is being built primarily for the CBSE Skill Expo and national-level student innovation evaluation.

The current priority is:
- strong frontend experience
- demo quality
- visual storytelling
- feature clarity
- interactive workflows
- AI functionality demonstrations

The current priority is NOT:
- enterprise-scale infrastructure
- production-grade DevOps
- cloud scalability
- distributed systems
- complex backend optimization

The product should feel:
- futuristic
- AI-powered
- visually impressive
- interactive
- easy to understand
- demo-friendly

while still maintaining believable technical depth.

---

# Product Identity

Green Credit AI is an AI-powered sustainability operating platform focused on:
- Scope 3 carbon intelligence
- ESG/BRSR automation
- sustainability verification
- greenwashing detection
- sustainability engagement
- AI-driven environmental intelligence

The system includes:
- B2B sustainability intelligence workflows
- B2C/community sustainability engagement
- AI-powered sustainability agents
- sustainability dashboards
- community sustainability systems
